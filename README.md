### Sobre mí

Soy desarrollador de software y especialista en infraestructura de redes y telecomunicaciones. Me apasiona construir **herramientas que conectan el mundo del desarrollo web con la operación técnica de redes (NOC / ISP)**, automatizando procesos críticos, monitoreando infraestructura en tiempo real y diseñando arquitecturas limpias y escalables.

- **Infraestructura & Redes (NOC / ISP):** Administración y monitoreo de redes GPON/OLT (SNMP), routers **MikroTik (RouterOS)**, VLANs, túneles VPN (Tailscale/WireGuard), **Zabbix** y laboratorios virtuales con **PNETLab**.
- **Desarrollo Full Stack:** Creación de dashboards operativos, sistemas de gestión y plataformas web modernas utilizando **React, Next.js, TypeScript, Node.js (Express), Python (FastAPI / PySide6)** y **PostgreSQL / TimescaleDB**.
- **SysAdmin & Homelab:** Virtualización con **Proxmox VE** (contenedores LXC y VMs), orquestación con **Docker Compose**, servidores Linux (Ubuntu/Debian/Alpine), automatización en **Bash / Python (Netmiko)** y sistemas de backup automatizados.
